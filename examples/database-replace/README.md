# The same question, answered twice

`prompt.txt` was sent to two live Claude Code sessions. One had `decision-layer`
armed; the other did not. Nothing else differed.

Both ran in a **clean configuration** — a fresh install holding this plugin and
nothing else. No personal instruction files, no project instructions, no other
plugins. That matters: a well-tuned setup already nudges Claude toward plainer
writing, which would flatter the unarmed side and understate the difference.

| file | session |
|---|---|
| [`without-decision-layer.md`](without-decision-layer.md) | plugin not armed |
| [`with-decision-layer.md`](with-decision-layer.md) | plugin armed |
